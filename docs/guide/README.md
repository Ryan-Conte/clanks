# Using clanks

These guides are for someone using the app. How it's built is in the [buildout plan](../PLAN.md), and where it's going is in the [roadmap](../ROADMAP.md).

1. [Getting started](getting-started.md): install it, pull a model, and watch the sample project run.
2. [Models](models.md): what runs on your machine, what fits, and using a cloud model or a server of your own.
3. [Projects and the board](projects.md): a project's crew, the spec, tickets, and what approving does.
4. [Routines](routines.md): work on a schedule, and posts that go out at a time you approved.
5. [Integrations and the marketplace](integrations.md): connecting services, and installing what others have shared.
6. [Privacy and permissions](privacy.md): what stays on your computer, what asks first, and what never happens without you.
7. [Troubleshooting](troubleshooting.md): when a model won't load, a run stops, or a post didn't go out.
